# 74 — a prompt scheduled to run later

## Goal

> Every acceptance criterion in GitHub issue #74 holds against a running axiom, and
> `uv run pytest` is green and hermetic — a user can ask for a prompt to run once at a
> named time or repeatedly on a schedule, see what is scheduled, cancel it by identifier,
> and have it run as an ordinary turn once the session is idle, with nothing written to
> disk and nothing surviving the session.
