# 80 — a message the user meant, however many lines it has

## Goal

> Every acceptance criterion in GitHub issue #80 holds against a running axiom, and
> `uv run pytest` is green — a user types ctrl+enter for a new line and enter to send,
> pastes a stack trace and gets one message rather than one turn per line, and finds
> every single-line session, every command and every piped run behaving exactly as they
> did before any of this existed.
