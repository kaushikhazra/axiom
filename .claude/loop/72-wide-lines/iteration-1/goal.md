# 72 — a quoted or listed line wider than the window

## Goal

> Every acceptance criterion in GitHub issue #72 holds against the real renderer, and
> `uv run pytest` is green and hermetic — a block quote, a bulleted item and a numbered
> item wider than the terminal are shown in full and wrapped, written once and never
> replaced by a shorter version, with paragraphs, headings, fenced code and table cells
> behaving exactly as they do today.
