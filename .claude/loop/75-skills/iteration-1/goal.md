# 75 — a skill axiom follows when the work calls for it

## Goal

> Every acceptance criterion in GitHub issue #75 holds against a running axiom, and
> `uv run pytest` is green, hermetic and fast — a user can write a skill once under
> `.axiom/skills/`, see it listed, run it themselves with `/skill`, and have the model
> reach for it unprompted when the work calls for it, with only its name and description
> ever riding on a request until the moment it is invoked.
