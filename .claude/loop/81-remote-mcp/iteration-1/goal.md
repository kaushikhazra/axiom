# 81 — a server that is already running somewhere else

## Goal

> Every acceptance criterion in GitHub issue #81 holds against a running axiom, and
> `uv run pytest` is green — a user names a server by address instead of by a command,
> its tools appear alongside every other tool and are called the same way, a server that
> cannot be reached is named with its reason while the session carries on without it, and
> a run with no remote servers configured behaves byte for byte as it does today.
